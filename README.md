## 💚 About StrayCare

StrayCare helps communities respond when animals need care. People can report an animal in need, while responders can discover and manage cases through a shared rescue workflow.

## ✨ What you can do

- 🚨 **Report animals in need** and share location details
- 🧭 **Coordinate rescue responses** with an active case workflow
- 🐕 **Join as a responder** and help with open cases
- 📊 **View rescue activity** through role-specific dashboards
- 🛡️ **Manage the platform** with administrator tools

## 🚀 Try the live app

👉 **[Open StrayCare](https://straycare-frontend-omega.vercel.app)**

The live frontend is hosted on Vercel and connects to an API hosted on Render. The demo backend uses temporary storage, so data and uploaded photos may not persist after a restart or redeployment.
